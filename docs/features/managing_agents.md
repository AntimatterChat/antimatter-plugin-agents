# Managing agents

Agents are the server's: system admins manage the server-wide agents in Integrations › Agents (System Console),
and a community's admins their community's agents in its settings. There, each agent gets its model connection and
model, its instructions, its tools and who may talk to it. The AI chat app no longer has a page of its own for them.

See the [Antimatter documentation](https://antimatter.chat/docs/) for the details.
